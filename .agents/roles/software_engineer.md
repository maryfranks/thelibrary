# Project Overview

"The Library" is a retro terminal-style text adventure web game built as a standalone single-page application. Players navigate a flooded, hazardous library stacks environment following an unnatural storm, solving environmental puzzles, managing inventory, and avoiding fatal encounters.

## Core Architecture: Strict 3-Tier Decoupling
1. Frontend UI Shell (`src/routes/index.tsx`, `src/components/`):
   - Presentational React interface simulating a tactile retro terminal console.
   - Captures raw keystrokes, provides command history navigation, and renders terminal output lines.
   - Completely decoupled from game rules; never inspects, parses, or imports `content.json`.
2. Headless Game Engine (`src/engine/`):
   - Pure TypeScript state machine and command dispatch system.
   - Governs room traversal, inventory tracking, item checks, and outcome evaluations.
   - 100% headless: zero React imports, zero DOM manipulation, zero browser-specific globals (`window`, `document`).

3. Narrative Content Catalog (`content.json`):
   - Static, author-owned string dictionary containing room descriptions, death screens, and parser messages.
   - Read-only data source ingested by the engine via typed schemas; never modified or generated by automated agents.

## Technology Stack & Tooling
- Runtime & Package Manager: Bun (`bunfig.toml`, `bun.lock`). Use `bun install`, `bun run test`, and `bun run build`.
- Framework & Routing: TanStack Start / React 19 / Vite.
- Styling: Tailwind CSS v4 configured via `src/styles.css` and strictly bound to `_docs/design_system.md`.
- Deployment Target: Cloudflare Pages (`thelibrary.littlefuzzydinos.com`).
- CLI / Version Control: GitHub CLI (`gh`).

## Testing Directives & Engineering Standards
- Follow all testing directives in `_docs/process.md`
- Isolation: Tests run strictly in Vitest without DOM or browser mocks.
- Deterministic Assertions: Test explicit node transitions, inventory state, and game flags (isGameOver, isWin) rather than narrative text.
- Bug Fixes: Every bug fix must include a reproducing regression test.
